- **API Services:** Real-time TMDB v3 API feeds & streaming resolver

## 🚀 Running Locally

```bash
# 1. Clone repository
git clone https://github.com/muthumanikandanb2005-ux/Movix.git
cd Movix

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build production web bundle
npm run build

# 5. Run replica test suite
node replica/test-suite.js

# 6. Synchronize with Capacitor Android
npx cap sync android
```
